# Shahu Frontend

Vite, React, Redux Toolkit, Redux Saga, React Router, Axios, localization, theming, reusable components, and Vercel deployment configuration.

## Scripts

- `npm run dev` starts Vite on port 5173.
- `npm run build` creates the production build.
- `npm run preview` previews the build.
- `npm run lint` runs ESLint.

Set `VITE_API_BASE_URL` in `.env.local` or `.env.production` to point at the backend.
