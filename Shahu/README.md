# Cognitix Academy Management System

The workspace contains the Vite web portal, Express/MongoDB API, and React Native Android app.

1. Configure `Backend/.env.local` and start MongoDB.
2. In `Backend`, run `npm install`, `npm run seed:admin`, and `npm run dev`.
3. In `Frontend`, run `npm install` then `npm run dev`.
4. In `ShahuAPP`, run `npm install` then `npm run android` with an emulator/device.

Default admin: `admin@cognitix.com` / `12345678`. Change this in production.

API reference: `Backend/API.md`. Interactive Swagger documentation is at `/api-docs`.
